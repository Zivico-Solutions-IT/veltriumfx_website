Replace the Indices hero image
---------------------------------


To replace the Indices hero image with your provided picture:

1. Save your new hero image file using the filename:

   `indices-hero.svg` (or keep the same extension as your image, e.g. `indices-hero.png`)

   and place it at: `src/assets/images/`

   Full path example:
   `d:/Office Work/Veltriumfx/veltriumfx_website/src/assets/images/indices-hero.svg`

2. The `Indices.jsx` page imports `indices-hero.svg` as the hero background; only that page will use it.

3. Restart the dev server if it was running:

```powershell
cd "d:/Office Work/Veltriumfx/veltriumfx_website"
npm run dev
```

If you want me to directly add the attached image file into the project (so it replaces the placeholder), say "Yes, add the image" and I'll place it at the correct path.
